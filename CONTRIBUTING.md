# Contributing

Run `./scripts/test.sh` and `./scripts/build.sh` before submitting UI changes.
Tests use synthetic readings and do not touch hardware. Do not invoke a live
USB capture as part of CI or an unrelated UI test.

Only contribute code you have the right to distribute under the repository's
MIT license. Do not add the excluded, unlicensed collector or copies of its
source/binaries. Do not add private hardware profiles or real captured data.

Describe macOS version, app version and steps to reproduce. Use the allowlisted
diagnostic report for debugging; inspect it before posting.
