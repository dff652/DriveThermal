# Security

Do not include credentials, serials, UUIDs, raw SMART dumps, enrollment files or
full capture logs in a public report. Prefer the app's allowlisted diagnostic
export and review it before sharing.

For sensitive vulnerabilities, use GitHub's private vulnerability reporting for
this repository when available. Do not post exploit details containing private
data to a public issue. Never disable SIP, reduce system security or force-unmount
a disk merely to make a capture succeed.
